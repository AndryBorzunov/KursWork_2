# КУРСОВАЯ РАБОТА № 2

- Программа для получения информации о вакансиях с платформы hh.ru в России,
  сохранения ее в файл.
- позволяет удобно работать с ней: добавлять, фильтровать, удалять.

## Модуль API

- Предназначен для работы с API стороннего сервиса

### HH_API

- Класс для получения данных о вакансиях с платформы Head Hunter

## Модуль MODELS

- В данном модуле реализован класс **Vacancy**, в котором хранится информация о параметрах вакансии
- Включает в себя такие атрибуты, как **Идентификационный номер** вакансии, **Наименование вакансии**, **зарплата**, **ссылка на вакансию**
- Позволяет сравнивать вакансии по зарплате

## Модуль STORAGE

- Реализация записи и чтения вакансий из файла

### JSON_STORAGE

- Класс, являющийся наследником абстрактного класса **AbstractStorage**
- Позволяет работать с JSON файлом

## Модуль UTILS

- Реализованы функции фильтрации вакансий по ключевым словам
- Фильтрация вакансий по уровню зарплаты
- Сортировка вакансий
